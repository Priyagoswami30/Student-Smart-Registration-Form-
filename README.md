🎓 Student Smart Registration Form
Deployed link- https://student-smart-registration-form.onrender.com. 

A clean and responsive Student Registration Form built using HTML5 and CSS3.
This project provides a simple and user-friendly interface for collecting student information such as name, email, password, roll number, phone number, and address.

✨ Features

- 📝 Student registration form
- 👤 First Name and Last Name fields
- 📧 Email input with HTML validation
- 🔐 Password field
- 🎓 Student Roll Number field
- 📱 Phone Number field
- 🏠 Address field
- ✅ Required field validation
- 🔄 Reset button to clear the form
- 📱 Fully responsive design
- 🎨 Modern gradient background
- 💫 Hover and focus effects
- 📦 Clean card-style form layout

🛠️ Technologies Used

- HTML5 – For creating the structure of the registration form
- CSS3 – For styling, responsive design, animations, and layout

🚀 How to Run the Project

1. Clone the Repository

2. Open the Project Folder

cd student-smart-registration-form

3. Run the Project

Open the "index.html" file in any modern web browser.

You can also use VS Code with Live Server to run the project.

🖥️ Form Details

The registration form collects the following information:

Field| Description
First Name| Student's first name
Last Name| Student's last name
Email| Student's email address
Password| Account password
Roll Number| University roll number
Phone Number| Student's contact number
Address| Student's address

The website includes:

- Box shadow

📱 Responsive Design

The form is designed to work across different screen sizes:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

On smaller screens, the form automatically adjusts to the available width and the buttons become full-width.
